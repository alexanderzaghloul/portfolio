# NEON VOID // Runner

A polished arcade-survival browser game built from scratch with **HTML5 Canvas, CSS, and vanilla JavaScript**. No frameworks, engines, external assets, or installs are required.

## Play locally

### Fastest method
Open `index.html` in any modern browser.

### Local development server
If Python is installed:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Windows users can double-click `launch-windows.bat`. macOS/Linux users can run `./launch-mac-linux.sh`.

## Controls

- `WASD` or arrow keys — move
- `SPACE` — dash
- `P` — pause

## Gameplay systems

- Progressive wave / difficulty system
- Three enemy behavior profiles
- Dash ability with cooldown meter and invulnerability window
- Health and recovery system
- Collectible energy shards
- Near-miss combo scoring
- Procedural particles, trails, grid effects, screen shake, and visual feedback
- Persistent local high score via `localStorage`
- Responsive interface for desktop and smaller displays

## Tech

- HTML5 Canvas rendering loop
- Delta-time movement and animation
- Vector-based enemy tracking
- Circle collision detection
- Procedural VFX / particles
- Persistent browser storage
- Zero runtime dependencies
