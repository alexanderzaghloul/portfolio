# Consent Ledger

Consent Ledger is a privacy-first digital identity prototype that models personal-data exposure across common digital services. It lets users simulate permission changes, see an estimated privacy-control score, quantify modeled annual data value, and record consent events in a local ledger.

## Features
- Interactive privacy Control Score
- Modeled annual value of active data relationships
- High-risk permission detection
- Privacy optimizer
- Category exposure visualization
- Consent event ledger stored locally
- Responsive dashboard UI

## Tech
HTML, CSS, vanilla JavaScript and LocalStorage.

All numbers in the demo are modeled/synthetic and illustrate the product concept rather than make factual claims about the value of an individual's data.
