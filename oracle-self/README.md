# ORACLE//SELF

**Simulate the system that simulates you.**

ORACLE//SELF is an interactive speculative-tech prototype exploring how synthetic behavioral signals can become algorithmic identity narratives—and what happens when the user can inspect and manipulate the model.

## Features
- Synthetic identity engine
- Interactive behavioral/economic/social signals
- Explainable model metrics
- Dynamic archetypes
- Canvas relationship graph
- Future branch simulator
- Dossier generator and local JSON export

## Tech
HTML5, CSS3, vanilla JavaScript, Canvas API and SVG.

The project intentionally avoids real-world social ranking and does not make employment, housing, credit, insurance or other eligibility decisions.
