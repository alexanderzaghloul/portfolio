# DataBearer

**Your data is an asset. Manage it like one.**

DataBearer is a working product prototype that reframes personal data as a portfolio: holdings, counterparties, exposure, concentration, consent history, controls and monthly statements.

## Product thesis
What if people could understand and manage their personal data using the same mental models they use for a financial portfolio?

## Prototype features
- Modeled personal-data value
- Portfolio allocation and exposure analysis
- Counterparty holdings
- Control Score
- Monthly Data Statement
- Consent Ledger
- Data Exchange / Consent API concept

## Important limitation
All portfolio/company relationship examples and dollar values are synthetic and illustrative. Modeled Data Value is not a cash appraisal, market price, investment return, or claim about revenue earned by any company from a specific person.

## Tech
HTML, CSS, JavaScript, structured synthetic datasets and financial-style modeling.
