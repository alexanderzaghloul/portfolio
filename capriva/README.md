# CAPRIVA

**Your data is an asset. Manage it like one.**

CAPRIVA is a product prototype that reframes personal-data privacy through the mental model of an investment portfolio. It presents data relationships as holdings, counterparties, exposure, concentration, controls and a monthly statement.

## Demo features
Modeled personal-data portfolio value, Control Score, category allocation, counterparty holdings, risk filtering, permission reduction simulation, exposure optimizer, monthly Data Statement, Consent Ledger, JSON export and Data Exchange concept.

## Tech
HTML, CSS and JavaScript. Static prototype with no build step.

All data and dollar values are synthetic and illustrative.
