# Ghostprint

**See the version of you the internet sees.**

Ghostprint is an interactive prototype for a personal-data intelligence product. It models how ordinary digital permissions can compound into a larger synthetic “data shadow” and lets a user reduce that exposure in real time.

## Core concepts
- Ghostprint Score
- Simulated Digital Twin
- Data Relationship Graph
- Rewind Engine
- Consent Memory
- Privacy Stress Test

## Tech
HTML, CSS, vanilla JavaScript, HTML5 Canvas and local JSON export. No backend required.

## Important limitation
This prototype does not access real user accounts, scrape data brokers, or claim to know a person's real profile. All outputs are synthetic simulations.
